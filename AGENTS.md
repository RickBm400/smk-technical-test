# AGENTS.md

Web application for CSV file management

## Repository

- `frontend/` - Vue application
- `backend/` - Express REST API
- `docs/` - project documentation

## Stack

### Frontend

- Vue
- TypeScript
- Vite
- PrimeVue
- Pinia
- Vue Router
- Axios
- Tailwind + CSS
- Vitest

### Backend

- Node.js
- Express
- TypeScript
- Zod
- Prisma with PostgreSQL
- JWT
- Jest

### Rules

- Use Vue with Option API !IMPORTANT
- Use Express with TypeScript !IMPORTANT
- Do not modify unrelated files
- Do not create commits unless explicitly required
- Avoid unnecessary dependencies
