# CSV Manager - Frontend

Vue 3 + TypeScript application for managing CSV files.

## Stack

- **Framework**: Vue 3 (Options API)
- **Language**: TypeScript
- **UI**: PrimeVue 4, PrimeIcons, Tailwind CSS
- **State**: Pinia
- **Router**: Vue Router
- **HTTP**: Axios
- **Build**: Vite
- **Testing**: Vitest

## Setup

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

Runs on http://localhost:5173

## Build

```bash
pnpm build
```

## Test

```bash
pnpm test
```

## Environment Variables

```
VITE_API_URL=/api
```
